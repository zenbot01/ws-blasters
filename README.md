# Blasters (Single Player)

A tiny single‑player blaster game that runs 100% in the browser:
- **Client:** plain HTML (Canvas)
- **No server required**

## Controls
- Move: **WASD** or **Arrow keys**
- Aim: **IJKL**
- Fire: **Space**
- Reset: **R**

## Run locally
Just open:

- `client/index.html`

## GitHub Pages
The `client/` folder is deployed to GitHub Pages via GitHub Actions.
